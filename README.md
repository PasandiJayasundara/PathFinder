# PathFinder

PathFinder is a web application that helps Sri Lankan university students discover the career journeys of graduates.

## Main Features

* Graduates can share their career journey.
* Students can explore different career paths.
* Users can learn about graduates' degrees and current jobs.
* Graduates can provide advice to current students.
* Students can discover potential mentors.

## Project Goal

The goal of PathFinder is to connect university students with authentic local career experiences and help them understand different career pathways.
